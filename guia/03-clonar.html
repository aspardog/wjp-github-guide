Cloning a Repository

How to download repositories from GitHub to your computer using HTTPS or SSH

Once you have Git installed and authenticated, the next step is to clone a repository. Cloning means creating a complete local copy of a remote repository (the one on GitHub).

Getting the Repository URL

Before cloning, you need the repository URL. On GitHub:

  1. Go to the repository you want to clone.
  2. Click the green Code button.
  3. You’ll see two URL options: HTTPS and SSH.

Method 1: Clone with HTTPS (recommended)

If you followed the setup guide and authenticated with gh auth login, this is the simplest method.

Step by step

  1. Copy the HTTPS URL of the repository. It has this format:

    https://github.com/USERNAME/REPO-NAME.git

  2. Open the terminal and navigate to the folder where you want to save the project:

    cd ~/Documents/projects

  3. Run the git clone command followed by the URL:

    git clone https://github.com/USERNAME/REPO-NAME.git

  4. Git will create a folder with the repository name and download all the content:

    Cloning into 'REPO-NAME'...
remote: Enumerating objects: 156, done.
remote: Counting objects: 100% (156/156), done.
remote: Compressing objects: 100% (89/89), done.
remote: Total 156 (delta 67), reused 134 (delta 52), pack-reused 0
Receiving objects: 100% (156/156), 45.23 KiB | 1.13 MiB/s, done.
Resolving deltas: 100% (67/67), done.

  5. Enter the project folder:

    cd REPO-NAME

Practical example

# Navigate to your projects folder
cd ~/Documents/GitHub

# Clone the repository
git clone https://github.com/worldjusticeproject/my-project.git

# Enter the project
cd my-project

# Verify everything is okay
git status
Note

If you authenticated correctly with gh auth login, Git won’t ask for username or password. Everything should work automatically.

Method 2: Clone with SSH

SSH is an alternative to HTTPS that uses cryptographic keys instead of tokens. It’s useful if you prefer not to depend on GitHub CLI or if you work in an environment where SSH is the standard.

SSH Key Configuration

Before you can clone with SSH, you need to generate a key pair and add the public key to GitHub.

Step 1: Generate the key pair

ssh-keygen -t ed25519 -C "your.email@worldjusticeproject.org"

When asked where to save the file, accept the default (Enter). When asked for a passphrase, you can leave it empty or set one (more secure).

This creates two files:

  • ~/.ssh/id_ed25519 — the private key. Never share it.
  • ~/.ssh/id_ed25519.pub — the public key. This one goes to GitHub.

Step 2: Add the public key to GitHub

Copy the content of the public key:

  • macOS
  • Windows (Git Bash)
  • Linux
pbcopy < ~/.ssh/id_ed25519.pub
cat ~/.ssh/id_ed25519.pub | clip
# With xclip
xclip -sel clip < ~/.ssh/id_ed25519.pub

# Or display and copy manually
cat ~/.ssh/id_ed25519.pub

Then on GitHub:

  1. Go to Settings → SSH and GPG keys.
  2. Click New SSH key.
  3. Give it a descriptive title (e.g., “WJP Laptop - MacBook 2025”).
  4. Paste the public key.
  5. Click Add SSH key.

Step 3: Verify the connection

ssh -T git@github.com

If everything is working, you’ll see:

Hi YOUR-USERNAME! You've successfully authenticated, but GitHub does not provide shell access.

The message “does not provide shell access” is not an error — it’s the expected behavior.

Clone with SSH

Once the keys are configured, cloning is the same as with HTTPS but using the SSH URL:

git clone git@github.com:USERNAME/REPO-NAME.git

The SSH URL has the format git@github.com:USERNAME/REPO.git (note the colon instead of slash after github.com).

Practical example

# Clone using SSH
git clone git@github.com:worldjusticeproject/my-project.git

# Enter the project
cd my-project

# Verify
git status

HTTPS or SSH?

Aspect HTTPS SSH
Setup Simpler with gh auth login Requires generating and configuring keys
Security Token stored by gh CLI Private key on your machine
Firewalls Works almost everywhere Some firewalls block port 22
Recommendation For most users If you prefer not to use gh CLI
Tip

If you already authenticated with gh auth login, use HTTPS. It’s simpler and works just as well.

Clone to a specific folder

By default, git clone creates a folder with the repository name. You can specify a different name:

# Clone to a folder called "my-copy"
git clone https://github.com/USERNAME/REPO-NAME.git my-copy

Final verification

After cloning, verify everything is okay:

# See the repository status
git status

# See the commit history
git log --oneline -5

# See the configured remotes
git remote -v

The git remote -v command should show:

origin  https://github.com/USERNAME/REPO-NAME.git (fetch)
origin  https://github.com/USERNAME/REPO-NAME.git (push)

This means your local copy is connected to the repository on GitHub (called “origin”).

Next step

Now that you have the repository cloned, you’re ready to start working with Git.
